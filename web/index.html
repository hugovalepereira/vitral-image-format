Image format · draft 0.1

.vitral

Blend modes that survive export.

A proposal for an image format that carries its own blend modes. What multiplies in Figma, Illustrator or Photoshop keeps multiplying on the website, without anyone rebuilding it.

01Try it

Same file, two viewers

A blend mode lives in the design tool, not in the file. Export a multiply layer and you get a flat PNG that looks grey on a new background, so someone rebuilds it by hand, or it gets flattened over one background and breaks when that changes.

02Make one

Export it from Figma

The Vitral plugin for Figma exports a layer as a .vitral.png in one click, blend modes included. It also places Vitral files back in Figma as layers that keep blending.

  1. 1Select a layerA frame, a group or a shape, with blend modes inside.
  2. 2Press Export .vitral.pngOne file, still a PNG, with the blends kept.
  3. 3Place it anywhereOn a website with one script tag, or back in Figma.
Get the Figma plugin A first version, installed from the repository. Not on Figma Community yet.

From another tool

Any tool that exports PNG can make one. Export the artwork over a black background and over a white one, and drop both files here: how each pixel changes between the two is what records the blending. A third export with no background is optional. It sets the picture that software without Vitral shows; leave it out and Vitral works that picture out from the other two. 03Use it

One script tag on the website

“It's a PNG. Add one script tag and it blends like it did in Figma.”What to tell your developer.
HTML
<img src="capsule.vitral.png" alt="Capsule">
<script type="module" src="vitral.js"></script>

With the script, every <img> whose file ends in .vitral.png blends with what is behind it on the page. It works on websites with the script and in Figma with the plugin. Everywhere else it shows the PNG you would export today, never worse.

04How it works

Two exports, one straight line

Each pixel stores how it looks over black and over white. Over anything else, it lands on the straight line between the two. Browsers already have the blend modes to draw that line, so the script only has to stack them.

Technical details
result=K+(W − K)×backdrop

K is the pixel over black and W the pixel over white, per colour channel. A renderer draws the line with three layers and the blend modes every browser and design tool has: difference, then screen, then multiply. These are the layers of the image selected above:

Blend modeIn draft 0.1
Normal, multiply, screen, hard light, exclusion, inversionexact, mixed per pixel and stacked
Add (plus-lighter), linear burn, darken, lighten, differenceapproximate: exact over black and white, a straight line between
Overlay, soft light, colour dodge and burn, hue, saturation, colour, luminosity, background blurnot yet

05Help shape it

A proposal, in the open

Vitral is an open proposal, published so that people who care about this problem can try it, break it and help improve it. Open an issue with your own exports, a case where you had to rebuild a blend by hand, or an idea for overlay, soft light or background blur.

PNG has transparency. Vitral has light and filter.
